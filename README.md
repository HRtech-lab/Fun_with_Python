# Fun with Python

Two early exercises introduce Python syntax and desktop graphics.

| File | What to expect |
| --- | --- |
| [Python language exercises](LearnPythonInOneHour/PythonInHour.py) | Notebook-style snippets on numbers, strings, collections and exceptions. Read them individually. Some snippets raise errors when the whole file is run as a script. |
| [Turtle drawing](MakingAppleLogo.py) | Draws an apple logo using the standard-library turtle module. Running it requires a desktop display and Python with Tk support. |

The legacy file `malware.py` can overwrite files in its working directory. Leave it unexecuted when exploring the exercises.
